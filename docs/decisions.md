# Decisões de projeto

Registro de decisões não cobertas (ou interpretadas) a partir do PRD (`.llm/prd.md`).

| #   | Data       | Decisão                                                                                                                                                                                                   | Motivo                                                                                                                     |
| --- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| D01 | 2026-10-16 | Banco de dev e testes: Neon, com branches `dev` e `test`; na CI, Postgres como service container do GitHub Actions.                                                                                       | A máquina de desenvolvimento não tem Docker.                                                                               |
| D02 | 2026-10-16 | Fluxo Git: um branch e um PR por fase do PRD (§13).                                                                                                                                                       | Revisão incremental.                                                                                                       |
| D03 | 2026-10-16 | A tolerância de +2s serve só para decidir se o tempo esgotou; o bônus de tempo usa o tempo real, `remaining = max(0, 30s − elapsed)`.                                                                     | Evita bônus negativo e mantém a fórmula da §4.                                                                             |
| D04 | 2026-10-16 | Trocar o idioma no meio da partida recarrega a pergunta atual no novo locale (`?locale=`).                                                                                                                | RF02 permite `locale` em cada chamada.                                                                                     |
| D05 | 2026-10-16 | Ranking "Semana" = últimos 7 dias corridos (UTC).                                                                                                                                                         | Mais simples que a semana-calendário e sem ambiguidade de fuso.                                                            |
| D06 | 2026-10-16 | Partidas expiram só de forma lazy (ao acessar), sem job agendado no MVP.                                                                                                                                  | O PRD §6.5 marca o job como opcional.                                                                                      |
| D07 | 2026-10-16 | O PDF de `docs_projeto/` não é versionado (`.gitignore`).                                                                                                                                                 | Binário grande, que não faz parte do produto.                                                                              |
| D08 | 2026-10-16 | pnpm instalado via `npm i -g pnpm@10`.                                                                                                                                                                    | `corepack enable` exige permissão de administrador nesta máquina.                                                          |
| D09 | 2026-10-17 | Next.js 16.4 com Cache Components (padrão do scaffold). Route handlers não exportam `runtime`, porque o runtime Node já é o padrão.                                                                       | Cache Components não aceita a config de segmento `runtime`.                                                                |
| D10 | 2026-10-17 | O seletor de idioma mostra só a sigla (PT · EN · DE), sem bandeira.                                                                                                                                       | Emojis de bandeira não renderizam no Windows, e bandeira não equivale a idioma.                                            |
| D11 | 2026-10-17 | Os scripts `db:migrate` e `db:studio` entram na F3, junto com o Prisma.                                                                                                                                   | Na F1 ainda não há schema; um script quebrado não ajuda.                                                                   |
| D12 | 2026-10-17 | B05 reescrita: "o Claude Code tem modos de permissão que definem o que ele faz sem pedir aprovação" (V), no lugar de "por padrão pede permissão antes de editar ou executar".                             | Nas versões atuais o modo inicial pode ser o auto mode, então a afirmação original deixou de ser sempre verdadeira.        |
| D13 | 2026-10-17 | A08 usa `Bash(npm run test *)`, a forma com espaço que a doc mostra como principal (`:*` continua aceito como equivalente).                                                                               | Alinhar o exemplo à documentação atual.                                                                                    |
| D14 | 2026-10-17 | Ajustes de redação baseados na doc: I06 cita `.claude/commands/` e `.claude/skills/` (comandos foram unificados em skills); A09 diz "containers ou VMs"; I02 e I04 ganharam um complemento na explicação. | Manter as explicações fiéis à documentação oficial.                                                                        |
| D15 | 2026-10-17 | `.gitattributes` com `* text=auto eol=lf`.                                                                                                                                                                | Com `core.autocrlf=true` no Windows, o checkout gravava CRLF e o Prettier (LF) marcava todos os arquivos como modificados. |
